# Oasis Recovery (Bradford) Home Page

CRITICAL — DO NOT GENERATE OR SOURCE ANY IMAGES

This project is currently focused on:

UX + UI + layout + mobile design only.

Do NOT generate any AI images.

Do NOT use an AI image-generation tool.

Do NOT search for stock photography.

Do NOT source images from Unsplash, Pexels or any other external image library.

Do NOT spend credits, tokens or generation effort finding, creating or selecting imagery.

I will manually upload and replace all website imagery after the design has been completed.

USE SIMPLE LETTER PLACEHOLDERS INSTEAD

Whenever the design requires an image, create a simple neutral placeholder block.

Inside the block place only a large letter.

For example:

A

B

C

D

etc.

Continue alphabetically throughout the homepage.

These letters are simply references that allow me to identify which image belongs in which position later.

Continue alphabetically wherever another image is required.

PLACEHOLDER DESIGN

Each image placeholder should:

use a simple neutral grey or subtle brand-neutral background;

preserve the exact intended image dimensions;

preserve the intended aspect ratio;

preserve border radius;

preserve spacing;

preserve responsive behaviour;

contain one large centred letter;

contain no generated artwork;

contain no illustration;

contain no decorative photography.

Example visual:

┌─────────────────────────────┐
│ │
│ A │
│ │
└─────────────────────────────┘

The letter should be large enough to identify easily but should not become a decorative design feature.

VERY IMPORTANT

Even though there are no real images, still design the image containers correctly.

Lovable must decide:

image width;

image height;

aspect ratio;

crop behaviour;

border radius;

mobile positioning;

tablet positioning;

desktop positioning;

whether the image is full-width;

whether images belong in a grid;

whether an image is portrait or landscape;

how much space photography should occupy within each section.

The placeholder should accurately represent the eventual real image.

MOBILE IMAGE PLACEHOLDERS

Because approximately 70% of visitors use mobile devices, image containers must be designed mobile-first.

At the 390px viewport:

Do not use unnecessarily tall image placeholders.

Prefer sensible mobile ratios such as:

4:3

3:2

1:1

and occasional portrait ratios only where genuinely appropriate.

The hero image should not consume an excessive amount of the first screen.

Important content and CTAs should remain higher priority than imagery.

RESPONSIVE BEHAVIOUR

The same placeholder letter should represent the same image across breakpoints.

For example:

Mobile:

[A]

Desktop:

[A]

Do NOT create different generated images for mobile and desktop.

Instead, define how the same eventual image should crop and resize responsively.
